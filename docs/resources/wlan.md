# unifi_wlan (Resource)

Manages a UniFi wireless network (SSID) configuration.

## Example Usage

```terraform
# Create a secure WPA2 wireless network
resource "unifi_wlan" "main" {
  name         = "MyNetwork"
  security     = "wpapsk"
  wpa_mode     = "wpa2"
  passphrase   = var.wifi_password
  ap_group_ids = [data.unifi_ap_group.default.id]

  # Optional: Associate with a specific network/VLAN
  network_id = unifi_network.main.id
}

# Create a guest network with isolation
resource "unifi_wlan" "guest" {
  name         = "Guest Network"
  security     = "wpapsk"
  wpa_mode     = "wpa2"
  passphrase   = var.guest_wifi_password
  ap_group_ids = [data.unifi_ap_group.default.id]

  is_guest     = true
  l2_isolation = true
}

# Create a WPA3 enabled network
resource "unifi_wlan" "secure" {
  name          = "Secure Network"
  security      = "wpapsk"
  wpa_mode      = "wpa2"
  wpa3_support  = true
  wpa3_transition = true
  passphrase    = var.secure_wifi_password
  ap_group_ids  = [data.unifi_ap_group.default.id]

  pmf_mode = "required"
}

# Tune minimum data rates and DTIM periods, e.g. for a dense IoT network
resource "unifi_wlan" "iot" {
  name         = "IoT"
  security     = "wpapsk"
  wpa_mode     = "wpa2"
  passphrase   = var.wifi_password
  ap_group_ids = [data.unifi_ap_group.default.id]
  wlan_band    = "2g"

  minrate_setting_preference = "manual"
  minrate_ng_enabled         = true
  minrate_ng_data_rate_kbps  = 6000
  dtim_mode                  = "custom"
  dtim_ng                    = 3
  mcastenhance_enabled       = true
}

variable "wifi_password" {
  type      = string
  sensitive = true
}

variable "guest_wifi_password" {
  type      = string
  sensitive = true
}

variable "secure_wifi_password" {
  type      = string
  sensitive = true
}

resource "unifi_network" "main" {
  name    = "Main Network"
  purpose = "corporate"
  vlan_id = 1
}
```

## Schema

### Required

- `ap_group_ids` (Set of String) Set of AP group IDs this WLAN should be broadcast on. Required.
- `name` (String) The SSID name of the wireless network.

### Optional

- `ap_group_mode` (String) How the WLAN selects APs to broadcast on. Valid values: 'all', 'groups', 'devices'.
- `bss_transition` (Boolean) Whether BSS transition is enabled. Defaults to true.
- `dtim_6e` (Number) The DTIM period on 6 GHz.
- `dtim_mode` (String) DTIM period mode. Valid values: 'default', 'custom'. The dtim_* periods apply when 'custom'.
- `dtim_na` (Number) The DTIM period on 5 GHz.
- `dtim_ng` (Number) The DTIM period on 2.4 GHz.
- `enabled` (Boolean) Whether the WLAN is enabled. Defaults to true.
- `fast_roaming_enabled` (Boolean) Whether fast roaming (802.11r) is enabled. Defaults to false.
- `group_rekey` (Number) The group key rotation interval in seconds. 0 disables rotation.
- `hide_ssid` (Boolean) Whether to hide the SSID. Defaults to false.
- `iapp_enabled` (Boolean) Whether the Inter-Access Point Protocol (IAPP) is enabled.
- `is_guest` (Boolean) Whether this is a guest network. Defaults to false.
- `l2_isolation` (Boolean) Whether L2 isolation is enabled. Defaults to false.
- `mac_filter_enabled` (Boolean) Whether MAC filtering is enabled. Defaults to false.
- `mac_filter_list` (Set of String) Set of MAC addresses for filtering.
- `mac_filter_policy` (String) MAC filter policy. Valid values: 'allow', 'deny'. Defaults to 'deny'.
- `mcastenhance_enabled` (Boolean) Whether multicast enhancement (multicast-to-unicast conversion) is enabled.
- `minrate_na_advertising_rates` (Boolean) Whether the 5 GHz minimum data rate also applies to beacons and other management frames.
- `minrate_na_data_rate_kbps` (Number) The minimum 5 GHz data rate in kbps.
- `minrate_na_enabled` (Boolean) Whether a minimum data rate is enforced on 5 GHz.
- `minrate_ng_advertising_rates` (Boolean) Whether the 2.4 GHz minimum data rate also applies to beacons and other management frames.
- `minrate_ng_data_rate_kbps` (Number) The minimum 2.4 GHz data rate in kbps.
- `minrate_ng_enabled` (Boolean) Whether a minimum data rate is enforced on 2.4 GHz.
- `minrate_setting_preference` (String) Whether minimum data rates are chosen automatically ('auto') or use the minrate_* values set here ('manual').
- `network_id` (String) The network ID (VLAN) to assign to this WLAN.
- `no2ghz_oui` (Boolean) Whether to keep clients with known 5 GHz-capable OUIs off 2.4 GHz.
- `passphrase` (String, Sensitive) The wireless passphrase (required for wpapsk security). Note: This value is write-only and cannot be read back from the controller.
- `passphrase_autogenerated` (Boolean) Whether the passphrase was generated by the controller.
- `pmf_mode` (String) Protected Management Frames mode. Valid values: 'disabled', 'optional', 'required'. Defaults to 'optional'.
- `proxy_arp` (Boolean) Whether proxy ARP is enabled. Defaults to false.
- `radius_das_enabled` (Boolean) Whether RADIUS Dynamic Authorization (CoA/disconnect) is enabled.
- `radius_mac_auth_enabled` (Boolean) Whether RADIUS MAC authentication is enabled.
- `radius_macacl_format` (String) The MAC address format sent to RADIUS for MAC authentication (e.g. 'none_lower').
- `schedule` (Set of String) Schedule configuration.
- `schedule_enabled` (Boolean) Whether scheduling is enabled. Defaults to false.
- `security` (String) The security mode. Valid values: 'open', 'wep', 'wpapsk', 'wpaeap'. Defaults to 'wpapsk'.
- `setting_preference` (String) Whether the controller manages this WLAN's advanced settings automatically ('auto') or uses the values set here ('manual').
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))
- `uapsd_enabled` (Boolean) Whether U-APSD (WMM Power Save) is enabled. Defaults to true.
- `user_group_id` (String) The user group ID for bandwidth limiting.
- `vlan` (Number) The VLAN ID for this WLAN. Note: On modern UniFi controllers (v8+), VLAN tagging is done by associating the WLAN with a network that has the desired VLAN ID.
- `vlan_enabled` (Boolean) Whether VLAN tagging is enabled. Defaults to false.
- `wlan_band` (String) The wireless band. Valid values: '2g', '5g', 'both'. Defaults to 'both'.
- `wlan_bands` (Set of String) Set of wireless bands to enable (e.g., '2g', '5g', '6g').
- `wpa3_enhanced_192` (Boolean) Whether WPA3 Enterprise 192-bit mode is enabled.
- `wpa3_fast_roaming` (Boolean) Whether fast roaming (802.11r) is enabled for WPA3.
- `wpa3_support` (Boolean) Whether WPA3 support is enabled. Defaults to false.
- `wpa3_transition` (Boolean) Whether WPA3 transition mode is enabled. Defaults to false.
- `wpa_enc` (String) The WPA encryption type. Valid values: 'ccmp', 'gcmp', 'auto'. Defaults to 'ccmp'.
- `wpa_mode` (String) The WPA mode. Valid values: 'auto', 'wpa1', 'wpa2'. Defaults to 'wpa2'. Note: WPA3 is controlled via wpa3_support attribute.
